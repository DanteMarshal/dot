# Review

Review the changes in the relevant scope and report the issues you find.
- Make sure the changes are consistent with the `coding` skill guidelines
- Categorize issues by "Blocking" and "Non-Blocking":
  - Blocking issues may include introduced bugs or important unmet guidelines
  - Non-blocking issues may include extra best-practice stuff
- Present the issues in a markdown table with an index column, so the user can easily refer to them.
